# BOS-TA: Forex Trader Mentorship Registration Platform

A web application for students to register for forex trading mentorship programs.

## 🎯 Purpose

BOS-TA provides a streamlined platform where interested students can:
- Register and create their profile
- Browse available mentors
- Apply for mentorship programs
- Track application status
- Connect with experienced forex traders for guidance

## 🛠️ Tech Stack

- **Frontend:** React/Next.js with TypeScript
- **Backend:** Node.js with Express
- **Database:** MongoDB
- **Authentication:** JWT
- **Styling:** Tailwind CSS
- **Email:** Nodemailer

## 📋 Features

- User registration and authentication
- Student profile creation
- Mentor directory and profiles
- Mentorship application system
- Email notifications
- Admin dashboard for mentor management
- Application tracking and status updates
